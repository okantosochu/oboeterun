# 覚えてるん♪ ～自分でつくる単語帳～ for 中学生

「入力は本人。記憶管理はアプリ。」を軸にした、スマートフォン向けの静的Web単語帳です。覚えていないことを責めず、もう一度出会うための復習予定を管理します。

## ファイル構成

- `index.html` — アプリの入口
- `styles.css` — スマートフォン優先の画面デザイン
- `js/config.js` — 教科・カテゴリ・試験タグ・復習間隔の設定
- `js/storage.js` — localStorage、ローカル日付、インポート検証
- `js/stories.js` — MAIN 180話の骨格とSIDE、冒頭仮本文
- `js/app.js` — 画面表示とアプリ機能
- `たこぴー.png` / `くらぴー.png` — 正式キャラクター画像（原本のまま参照）
- `tests/core.test.html` — ブラウザで実行する基本ロジックテスト

## ローカルで確認する

`index.html` をブラウザで直接開けます。より本番に近い確認には、このフォルダーで簡易HTTPサーバーを起動してアクセスしてください。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000/` を開きます。

## GitHub Pagesで公開する

1. このフォルダー一式をGitHubリポジトリの既定ブランチへ追加します。
2. GitHubのリポジトリ設定で **Pages** を開きます。
3. **Deploy from a branch** を選び、既定ブランチの `/ (root)` を公開元にします。
4. 表示された公開URLへアクセスします。

ビルド処理やサーバーは不要です。相対パスだけを使用しているため、プロジェクトページでも動作します。

## データ保存方式

データはブラウザの `localStorage` にJSON形式で保存します。カード、評価履歴、復習予定、進路、試験、学習日、物語の解放・既読状態を、`schemaVersion: 2` の単一データとして管理します。保存キーはv0.1と同じ `oboeterun-v01` を維持し、既存データを読み込み時に互換移行します。日付は端末のローカル日付を `YYYY-MM-DD` で扱い、UTC変換を避けています。

## バックアップ

ホーム下部の「設定・データ管理」からJSONを書き出せます。「データを読み込む」で復元できます。読み込み時は必須構造を検査し、確認後に現在データを置き換えます。

## v0.2

- 保存キー `oboeterun-v01` を維持したまま schema 2 へ互換移行します。旧カードの出題方向は「表 → 裏」です。
- カードの一覧・検索・教科絞り込み・編集・確認付き削除に対応。
- カードごとの表裏出題方向、使い方、節目と再訪の会話、PWAアイコンを追加。

## 既知の制限

- データは端末・ブラウザごとに独立し、自動同期されません。
- MAIN 001〜180はデータ骨格を収録していますが、完成本文は冒頭5話のみです。
- SIDEは動作確認用の4話です。
- 物語の進行配分は初回利用日と最終受験予定日による単純な比例モデルです。
- 独自試験タグ追加、詳細な学習統計は今後の拡張対象です。
